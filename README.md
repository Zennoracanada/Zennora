# Zennora website

Static GitHub Pages website for zennora.ca.

## Files
- `index.html` — main business page
- `dental.html` — dental clinic solution page
- `style.css` — shared responsive styles
- `site.js` — mobile navigation, current year and email-based lead form
- `robots.txt` / `sitemap.xml` — basic search-engine discovery
- `CNAME` — custom domain

The Voiceflow widget is embedded in both HTML pages using project ID `6a5e5220ff0e0c39c847f63b`.
