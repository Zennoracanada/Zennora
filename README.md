# Zennora website

GitHub Pages-ready static website.

## Upload
Upload every file in this folder to the root of the GitHub repository.

## Important settings
- Custom domain: `zennora.ca`
- Contact email: `zennora.ca@gmail.com`
- Calendly booking page: `https://calendly.com/zennora`
- Keep the `CNAME` file in the repository root.

## Main files
- `index.html`
- `dental.html`
- `style.css`
- `site.js`
